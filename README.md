# 발췌기 니니닝! 🐰

## 기능

- **대사 → 말풍선 한 번에**: 버튼 하나로 형식에 맞는 대사를 전부 말풍선으로 바꾸거나 다시 글로 되돌리기
  - **대사 형식 고르기**: `"텍스트"` `'텍스트'` `「텍스트」` `『텍스트』` `**텍스트**` `*텍스트*` `(텍스트)` `<텍스트>` `[텍스트]` `— 텍스트` 중 여러 개 선택
  - **기호 직접 지정**: `⧼ … ⟯` 처럼 여는/닫는 기호를 직접 추가 (닫는 기호는 생략 가능 → 그 기호로 시작하는 줄 전체)
  - **기호 없는 줄이 대사** 모드: 기호로 감싼 줄을 지문으로, 나머지를 대사로
  - `이름: 대사`, `[이름] 대사` 로 화자 지정 · 미리보기에서 말풍선을 눌러 캐릭터 · 위치 · 모양 변경 또는 말풍선 해제
  - 서식 도구 막대: **굵게** · *기울임* · 밑줄 · 취소선 · 형광펜(색 · 모양을 바로 선택), 단축키 Ctrl/⌘ + B · I · U, Shift + X · H
  - `**굵게**` `*기울임*` `__밑줄__` `~~취소선~~` `==형광펜==`, 빈 줄 1개는 문단 나눔 · 2개 이상은 장면 전환, `---` 구분선
  - 입력창 위 빠른 입력 버튼, `.txt` 파일 끌어다 놓기
- **내 프리셋** (맨 아래 ‘프리셋’ 탭): 서체 · 말풍선 · 배경 · 비율 · 스킨 · 대사 형식을 이름 붙여 저장하고 다시 적용 (캐릭터 이름 · 사진 · 색 포함). `.ninining.json` 파일로 보관 · 불러오기 — 브라우저 캐시를 지우면 목록이 사라지니 파일로도 보관
- **템플릿 12종** (‘프리셋’ 탭): 따뜻한 종이, 미니멀 화이트(기본), 다크 노블, 메신저, 단정한 페이지, 인용 카드, 라인 메신저, 중경삼림 무드, 영화 자막, 파스텔, 빈티지, 레트로 터미널. 한 번 누르면 서체 · 색 · 말풍선 · 스킨이 함께 바뀌고, 글과 캐릭터는 그대로 유지
- **말풍선 모양 14가지**: 둥근, 알약, 각진, 메신저, 생각 구름, 외침, 외곽선, 점선, 세로 라인, 텍스트만, 게임창, 레트로, 만화, 시스템 메시지
  - 미리보기에서 말풍선을 누르면 그 말풍선만 화자 · 위치 · 모양을 바꿀 수 있음
- **캐릭터**: 이름, 얼굴 사진(프로필 원을 눌러 파일 · 이미지 링크, 또는 끌어다 놓기), 위치, 개별 색상, 개별 말풍선 모양, 순서 변경
  - **아, 캐릭터 너무 많아!**: `어린 왕자, 장미, 여우`처럼 쉼표로 구분해 넣으면 기본 모양(하얀 배경 · 검은 글씨 · 왼쪽)으로 한 번에 추가
- **타이포그래피** (항목별 접이식): 본문 · 말풍선 · 제목 · 출처(작품명 / 제작자 따로)를 각각 설정. 한글 웹폰트 23종을 글꼴 모양 그대로 미리 보며 고르기 + 직접 입력, 장식 따옴표, 형광펜 색
- **기본값**: 본문 13.5px(약 10pt) · 행간 1.7, 화면 비율 ‘자유’, 한 줄 글자 수 표시, 문단 간격 또는 첫 줄 들여쓰기(둘 중 하나만), 장면 전환·말풍선 뒤 첫 문단은 들여쓰기 생략, 마지막 줄 외톨이 단어 방지(`text-wrap: pretty`), 페이지 끝 문단은 줄 단위로 나눠 다음 장에 이어 붙이고 외톨이·과부 줄 방지
  - 빈 줄 1개는 문단 나눔, 2개 이상은 장면 전환 여백
- **배경**: 단색 · 그라데이션(추천 12종, 직선/원형, 각도) · 패턴(점, 격자, 줄 노트, 사선, 체크, 플러스, 종이 질감, 원고지) · 이미지
- **화면**: 1:1 · 4:5 · 3:4 · 2:3 · 9:16 · 16:9 · 4:3 · 자유 비율
  - **한 장에 맞추기**: 글자 크기를 자동으로 조절해 한 장에 꽉 차게
  - **넘치면 다음 장으로**: 긴 글을 자동으로 여러 장으로 나눔 · 페이지 번호
- **스킨**
  - **HTML 배경**: `<style>` 태그와 HTML로 카드 배경을 직접 꾸미기. `body`가 카드 한 장 크기로 그려져 글 뒤에 깔리고, `data-layer="top"` 장식은 글 위에. 외부 이미지 · 웹폰트(`@import`)도 포함해 저장
  - **CSS 스킨**: 글 · 말풍선 · 제목 요소를 CSS로 직접 바꾸기 (예시 7종). 배경 코드를 이 칸에 넣으면 자동으로 HTML 배경으로 옮겨 줌
- **저장 · 복사 · 공유**: 1~3배 PNG, 여러 장 한 번에 저장, 상단 ‘복사’ 버튼으로 클립보드에 바로 복사, 모바일 공유 시트
  - **저장 폴더 지정** (Chrome · Edge 데스크톱): 원하는 폴더를 한 번 지정하면 ‘이미지 저장’이 그 폴더에 바로 쌓임. 파일명에 날짜·시간이 붙고 같은 이름은 (2)로 저장. 다른 브라우저는 다운로드 폴더로 저장
- **편의 기능**: 실행 취소/다시 실행, 미리보기 확대/축소, 자동 저장, 설정 파일 내보내기/불러오기
- **반응형**: 웹은 3단 레이아웃, 모바일은 아래 탭 바 + 바텀 시트로 미리보기를 보면서 편집
- 시스템 다크 모드 지원

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `excerpt-studio`).
2. 이 폴더의 파일을 저장소에 올립니다.

   ```bash
   git remote add origin https://github.com/<내 아이디>/excerpt-studio.git
   ```

   ```bash
   git push -u origin main
   ```

   또는 GitHub 웹 화면에서 **Add file → Upload files** 로 `index.html`, `style.css`, `app.js`, `lib/` 폴더를 끌어다 놓아도 됩니다.
3. 저장소의 **Settings → Pages** 에서 **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 를 선택하고 저장합니다.
4. 1~2분 뒤 `https://<내 아이디>.github.io/excerpt-studio/` 에서 열립니다.

로컬에서 확인하려면 폴더에서 `python3 -m http.server` 를 실행하고 `http://localhost:8000` 을 여세요.
(`index.html` 파일을 더블클릭해서 열면 이미지 저장 시 폰트가 빠질 수 있습니다.)

## 스킨 작성법

스킨 탭에 CSS를 쓰면 기본 디자인 위에 덮어씌워집니다.

```css
/* 변수로 색만 바꾸기 */
.card {
  --card-bg: #101418;
  --text-color: #e6e6e6;
  --b-bg: #1f2933;
  --b-color: #fff;
  --name-color: #8fa3b8;
}

/* 특정 캐릭터만 */
.msg[data-speaker="닝"] .bubble { background: #ffe14d; color: #222; }

/* 눈누 등 외부 웹폰트 */
@font-face {
  font-family: 'MyFont';
  src: url('https://example.com/MyFont.woff2') format('woff2');
}
.card .narr { font-family: 'MyFont'; }
```

| 선택자 | 설명 |
| --- | --- |
| `.card` | 이미지 한 장 |
| `.card-title` / `.quote-mark` / `.card-footer` / `.credit` / `.page-num` | 제목 · 장식 따옴표 · 하단 · 출처 · 페이지 번호 |
| `.card-content` / `.flow` | 본문 영역 |
| `.narr` / `.gap` / `.divider` / `mark` | 서술 문단 · 빈 줄 · 구분선 · 형광펜 |
| `.msg` | 말풍선 한 줄 (`.msg-left` `.msg-right` `.msg-center`, `.kind-speech` `.kind-thought`, `.shape-*`) |
| `.avatar` / `.name` / `.bubble` | 사진 · 이름 · 말풍선 |

주요 변수: `--card-bg --text-color --text-font --text-size --b-bg --b-color --b-border --b-radius --b-font --name-color --title-color --credit-color --accent --hl`

> 외부 폰트를 이미지에 넣으려면 해당 폰트 서버가 CORS를 허용해야 합니다 (Google Fonts, jsDelivr, 눈누 CDN 대부분은 허용).
